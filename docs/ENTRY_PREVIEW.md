# Entry map preview

- `scripts/publish-entry-map.ts` uses locally published Census tract population and boundaries to generate the decorative national population-glow SVG. It is a smoothed illustration, not satellite imagery or an urban/rural classification. `scripts/entry-heat-field.ts` sums neighboring population kernels before applying a continuous color ramp and embeds the resulting small PNG field inside the SVG. Dense regions merge into bright areas; sparse cells keep a softer texture. All field calculations happen at build time. One SVG image moves with the camera; there are no per-light browser animations or runtime provider calls.
- The same script publishes the exact six selected tracts' population and median household income from `data/tracts.bin` into `lib/content/entryTractFacts.json`. Selection depends on geometry, not socioeconomic merit. Missing values remain missing. Source: U.S. Census Bureau, 2020–2024 ACS, B01003 and B19013; income levels are in 2024 dollars.
- `scripts/publish-entry-growth.ts` fetches and caches only those six tracts' 2016–2020 ACS baselines from the existing registered Census source. It checks the returned GEOID, suppresses missing/zero baselines and capped income comparisons, and publishes descriptive percentage changes. No upstream calls occur when visitors view the popup.
- Popup arrows use a neutral shared color. They describe differences between overlapping 2016–2020 and 2020–2024 five-year estimates, not annual growth, demonstrated statistical significance, or desirability. Income changes are nominal. The Census Bureau generally recommends nonoverlapping periods for ACS comparisons; this specifically requested 2020-release to 2024-release comparison is labeled as overlapping and must not be used as a significance claim.
- Citation text travels with each popup, and public source links remain available in the introduction. The small callout is anchored above the selected polygon and appears after the highlight and scan. Reduced-motion and pause behavior remain.

Regenerate with `node --import tsx scripts/publish-entry-map.ts` and, when needed, `node --import tsx scripts/publish-entry-growth.ts`. Baseline fetches use the existing private Census key and redacted pipeline logging. Data-integrity tests compare selected GEOIDs, values, periods, and stored baseline calculations.

Reference: https://www.census.gov/programs-surveys/acs/guidance/comparing-acs-data.html
